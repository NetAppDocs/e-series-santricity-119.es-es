= Ver paquetes de estadísticas iSCSI en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes ver datos sobre las conexiones iSCSI a tu matriz de almacenamiento.

.Acerca de esta tarea
System Manager muestra estos tipos de estadísticas iSCSI. Todas las estadísticas son de solo lectura y no se pueden configurar.


NOTE: Los tipos de estadísticas que se muestran en System Manager se basan en las estadísticas disponibles para tu matriz de almacenamiento.

* *Ethernet MAC statistics* -- Proporciona estadísticas para el control de acceso al medio (MAC). MAC también proporciona un mecanismo de direccionamiento llamado dirección física o dirección MAC. La dirección MAC es una dirección única que se asigna a cada adaptador de red. La dirección MAC ayuda a entregar paquetes de datos a un destino dentro de la subred.
* *Ethernet TCP/IP statistics* -- Proporciona estadísticas para el TCP/IP, que es el Protocolo de Control de Transmisión (TCP) y el Protocolo de Internet (IP) para el dispositivo iSCSI. Con TCP, las aplicaciones en hosts en red pueden crear conexiones entre sí, sobre las cuales pueden intercambiar datos en paquetes. El IP es un protocolo orientado a datos que comunica datos a través de una inter-red conmutada por paquetes. Las estadísticas de IPv4 y las estadísticas de IPv6 se muestran por separado.
* *Estadísticas del kernel Ethernet* -- Proporciona estadísticas para los controladores del kernel de plataforma del dispositivo iSCSI. Las estadísticas del kernel muestran datos de red similares a los de la opción de estadísticas TCP/IP. Sin embargo, los datos de las estadísticas del kernel se recopilan de los controladores del kernel de plataforma en lugar de directamente del hardware iSCSI.
* *Local Target/Initiator (Protocol) statistics* -- Muestra estadísticas para el target iSCSI, que proporciona acceso a nivel de bloque a sus medios de almacenamiento, y muestra las estadísticas iSCSI para la storage array cuando se utiliza como initiator en operaciones de mirroring asíncrono.
* *DCBX Operational States statistics* -- Muestra los estados operativos de las distintas funciones de Data Center Bridging Exchange (DCBX).
* *LLDP TLV statistics* -- Muestra las estadísticas de tipo, longitud y valor (TLV) del protocolo Link Layer Discovery Protocol (LLDP).
* *DCBX TLV statistics* -- Muestra la información que identifica los puertos host de la storage array en un entorno Data Center Bridging (DCB). Esta información se comparte con los peers de la red para fines de identificación y capacidad.


Puedes ver cada una de estas estadísticas como estadísticas sin procesar o como estadísticas de línea de base. Las estadísticas sin procesar son todas las estadísticas que se han recopilado desde que se iniciaron los controladores. Las estadísticas de línea de base son estadísticas de un momento específico que se han recopilado desde que estableciste la hora de línea de base.

.Pasos
. Selecciona menú:Support[Support Center > Diagnostics] tab.
. Selecciona *Ver paquetes de estadísticas iSCSI*.
. Haz clic en una pestaña para ver los diferentes conjuntos de estadísticas.
. Para fijar la línea de base, haz clic en *Fijar nueva línea de base*.
+
Configurar la línea de base establece un nuevo punto de partida para la recopilación de las estadísticas. Se usa la misma línea de base para todas las estadísticas iSCSI.
