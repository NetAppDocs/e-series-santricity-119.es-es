= Conoce los errores de actualización de software y firmware de SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pueden ocurrir errores durante la actualización del software del controlador o la actualización del firmware de la unidad.

[cols="25h,~,~"]
|===
| Error de descarga del firmware | Descripción | Acción recomendada 


 a| 
Unidades asignadas con errores
 a| 
No se pudo actualizar una unidad asignada en la matriz de almacenamiento.
 a| 
La causa de este error puede ser que la unidad no tenga la firma apropiada. Asegúrese de que la unidad afectada sea una unidad autorizada. Póngase en contacto con el soporte técnico para obtener más información.

Al reemplazar una unidad, asegúrese de que la capacidad de la unidad de reemplazo sea igual o mayor que la de la unidad con error que desea reemplazar.

Puede reemplazar la unidad con error mientras la cabina de almacenamiento recibe I/O.



 a| 
Unidades de repuesto integradas
 a| 
Si la unidad está marcada como hot spare y está en uso para un grupo de volúmenes, el proceso de actualización del firmware falla.
 a| 
Esta condición de error debe corregirse antes de que puedas actualizar el firmware. Abre System Manager y usa Recovery Guru para resolver el problema.



 a| 
Grupos de volúmenes incompletos
 a| 
Si alguna unidad que forma parte de un grupo de volúmenes se omite, se retira o no responde, se considera un grupo de volúmenes incompleto. Un grupo de volúmenes incompleto impide las actualizaciones de firmware.
 a| 
Si uno o más grupos de volúmenes o pools de discos están incompletos, debes corregir esta condición de error antes de poder actualizar el firmware. Abre System Manager y usa Recovery Guru para resolver el problema.



 a| 
Operaciones exclusivas (que no sean análisis de medios en segundo plano/paridad) en ejecución en alguno de los grupos de volúmenes
 a| 
No se puede actualizar el firmware si hay operaciones exclusivas en curso en un volumen.
 a| 
Si existe una o varias operaciones exclusivas en curso, es necesario completarlas para poder actualizar el firmware. Utilice System Manager para supervisar el progreso de las operaciones.



 a| 
Volúmenes faltantes
 a| 
No se puede actualizar el firmware si falta algún volumen.
 a| 
Debes corregir la condición de volumen faltante antes de poder actualizar el firmware. Abre System Manager y usa Recovery Guru para resolver el problema.



 a| 
El estado de alguna de las controladoras no es óptimo
 a| 
No se puede actualizar el firmware si alguno de los controladores está en un estado distinto al óptimo.
 a| 
Uno de los controladores de la matriz de almacenamiento necesita atención. Esta condición debe corregirse antes de que se pueda actualizar el firmware. Abre System Manager y usa Recovery Guru para resolver el problema.



 a| 
Error en la verificación de la controladora de base de datos de SPM
 a| 
No se puede actualizar el firmware porque la base de datos de asignaciones de particiones de almacenamiento está dañada.
 a| 
Se produjo un error en la base de datos de asignación de particiones de almacenamiento de una controladora. Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Validación de la base de datos de configuración (si es compatible con la versión del controlador de la storage array)
 a| 
No se puede actualizar el firmware porque la base de datos de configuración está dañada.
 a| 
Se produjo un error en la base de datos de configuración de una controladora. Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Comprobaciones relacionadas con MEL
 a| 
No se puede actualizar el firmware porque el registro de eventos contiene errores.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se notificaron más de 10 eventos críticos MEL o informativos DDE en los últimos 7 días
 a| 
No se puede actualizar el firmware porque hay más de 10 eventos MEL informativos o críticos de DDE reportados en los últimos siete días.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se notificaron más de 2 eventos críticos MEL de página 2C en los últimos 7 días
 a| 
No se puede actualizar el firmware porque hay más de dos eventos MEL críticos de la página 2C reportados en los últimos siete días.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se notificaron más de 2 eventos críticos MEL de canal de unidad degradado en los últimos 7 días
 a| 
No se puede actualizar el firmware porque se han notificado más de dos eventos MEL críticos de canal de unidad degradado en los últimos siete días.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se notificaron más de 4 entradas cruciales MEL en los últimos 7 días
 a| 
No se puede actualizar el firmware porque hay más de cuatro entradas de registro de eventos críticos reportadas en los últimos siete días.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se requiere una dirección IP de gestión válida.
 a| 
Se necesita una dirección IP válida del controlador para realizar esta operación.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
El comando requiere una dirección IP de gestión activa para cada controlador.
 a| 
Se requiere una dirección IP de controlador para cada controlador asociado con la matriz de almacenamiento para esta operación.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se devolvió un tipo de archivo de descarga no gestionado.
 a| 
El archivo de descarga especificado no es compatible.
 a| 
Póngase en contacto con el soporte técnico para resolver este problema.



 a| 
Se produjo un error durante el procedimiento de carga y descarga de firmware.
 a| 
La descarga de firmware falló porque el controlador no puede procesar la solicitud. Verifica que la matriz de almacenamiento esté óptima y vuelve a intentar la operación.
 a| 
Si este error vuelve a ocurrir después de verificar que la matriz de almacenamiento es óptima, contacta al soporte técnico para resolver este problema.



 a| 
Ocurrió un error durante el procedimiento de activación del firmware.
 a| 
La activación del firmware falló porque el controlador no puede procesar la solicitud. Verifica que la matriz de almacenamiento esté óptima y vuelve a intentar la operación.
 a| 
Si este error vuelve a ocurrir después de verificar que la matriz de almacenamiento es óptima, contacta al soporte técnico para resolver este problema.



 a| 
Se ha agotado el tiempo de espera mientras se esperaba que el controlador {0} se reiniciara.
 a| 
El software de gestión no puede volver a conectarse al controlador {0} después de un reinicio. Verifica que haya una ruta de conexión operativa hacia la matriz de almacenamiento y vuelve a intentar la operación si no se completó correctamente.
 a| 
Si este error vuelve a ocurrir después de verificar que la matriz de almacenamiento es óptima, contacta al soporte técnico para resolver este problema.

|===
Puedes corregir algunas de estas condiciones usando el Recovery Guru en System Manager. Sin embargo, para algunas de las condiciones, puede que necesites ponerte en contacto con soporte técnico. La información sobre la descarga más reciente del firmware del controlador está disponible desde la storage array. Esta información ayuda a soporte técnico a entender las condiciones de error que impidieron la actualización y descarga del firmware.
