= Compatibilidad del software SANtricity con navegadores y sistemas operativos
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El software SANtricity es compatible con varios tipos de navegadores y sistemas operativos.



== Navegadores

Se admiten los siguientes exploradores en las versiones mencionadas.

[cols="1a,1a"]
|===
| Explorador | Versión mínima 


 a| 
Google Chrome
 a| 
89



 a| 
Mozilla Firefox
 a| 
80



 a| 
Safari
 a| 
14



 a| 
Microsoft Edge
 a| 
90

|===
[NOTE]
====
Para Unified Manager, el Web Services Proxy debe estar instalado y disponible para el navegador. Para más información, consulta https://docs.netapp.com/us-en/e-series/web-services-proxy/index.html["Descripción general de SANtricity Web Services Proxy"^]

====
