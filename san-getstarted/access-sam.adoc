= Accede a SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para acceder a la interfaz de usuario de SANtricity System Manager, apuntas un navegador a la dirección IP del controlador. Un asistente de configuración te ayuda a empezar con la configuración del sistema.

.Antes de empezar
* Instala y configura tu hardware, como se describe en una de las guías de configuración exprés:
+
** https://docs.netapp.com/us-en/e-series/config-linux/index.html["Configuración exprés de Linux"^]
** https://docs.netapp.com/us-en/e-series/config-vmware/index.html["Configuración exprés de VMware"^]
** https://docs.netapp.com/us-en/e-series/config-windows/index.html["Configuración exprés de Windows"^]


* Configura una estación de gestión que cumpla los siguientes requisitos:
+
** Conectado a una red que es de 1 Gbps o más rápida.
** Conectado a la misma subred que los puertos de gestión de almacenamiento.
** Se utiliza como una estación independiente, en lugar de un host (I/O conectadas) utilizado para la gestión de datos.
** Configura para la gestión fuera de banda, en la que una estación de gestión de almacenamiento envía comandos al sistema de almacenamiento a través de las conexiones Ethernet al controlador.
** Configura con un navegador compatible. Consulta link:supported-browsers-os.html["Navegadores y sistemas operativos compatibles"].




.Pasos
. Desde tu navegador, introduce la siguiente URL: `+https://<IPAddress>+`
+
`IPAddress` es la dirección de uno de los controladores de la matriz de almacenamiento.

+
La primera vez que se abre System Manager en una matriz que no se ha configurado, aparece el mensaje Set Administrator Password.

. Ingresa la contraseña de System Manager para el rol de admin en los campos Establecer contraseña de administrador y Confirmar contraseña, y luego haz clic en *Set Password*.
+
El asistente de configuración se inicia al iniciar sesión por primera vez.

. Usa el asistente de configuración para realizar las siguientes tareas:
+
** *Verifica el hardware (controladores y unidades)* -- Verifica el número de controladores y unidades en la matriz de almacenamiento. Asigna un nombre a la matriz.
** *Verifica hosts y sistemas operativos* -- Verifica los tipos de hosts y sistemas operativos a los que puede acceder la matriz de almacenamiento.
** *Accept pools* -- acepta la configuración de pool recomendada para el método de instalación express. Un pool es un grupo lógico de unidades.
** *Configurar alertas* -- Permite que System Manager reciba notificaciones automáticas cuando ocurre un problema con la matriz de almacenamiento.
** *Habilita AutoSupport* -- Supervisa automáticamente el estado de tu matriz de almacenamiento y haz que se envíen notificaciones al soporte técnico.




Para más información sobre el asistente de configuración, consulta link:../sm-interface/setup-wizard-overview.html["Descripción general del asistente de configuración"].
