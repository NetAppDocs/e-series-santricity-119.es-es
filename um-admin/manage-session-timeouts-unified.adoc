= Administra los tiempos de espera de sesión en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes configurar tiempos de espera para SANtricity Unified Manager, así las sesiones inactivas de los usuarios se desconectan después de un tiempo especificado.

.Acerca de esta tarea
Por defecto, el tiempo de espera de la sesión para Unified Manager es de 30 minutos. Puedes ajustar ese tiempo o también puedes desactivar por completo el tiempo de espera de la sesión.


NOTE: Si Access Management se configura usando las capacidades de Security Assertion Markup Language (SAML) integradas en la matriz, puede ocurrir un tiempo de espera de la sesión cuando la sesión de SSO del usuario alcanza su límite máximo. Esto puede ocurrir antes del tiempo de espera de la sesión de System Manager.

.Pasos
. En la barra de menús, selecciona la flecha desplegable que está junto a tu nombre de usuario.
. Selecciona *Activar/Desactivar tiempo de espera de sesión*.
+
Se abre el cuadro de diálogo Enable/Disable Session Timeout.

. Usa los mandos giratorios para aumentar o disminuir el tiempo en minutos.
+
El tiempo de espera mínimo que puedes configurar es de 15 minutos.

+
[NOTE]
====
Para desactivar los tiempos de espera de la sesión, desmarca la casilla *Set the length of time...*.

====
. Haz clic en *Guardar*.
