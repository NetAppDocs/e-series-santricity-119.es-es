= Cambia las contraseñas de la matriz de almacenamiento en SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes actualizar las contraseñas usadas para ver y acceder a las matrices de almacenamiento en SANtricity Unified Manager.

.Antes de empezar
* Debes iniciar sesión con un perfil de usuario que incluya permisos de administrador de almacenamiento.
* Debes conocer la contraseña actual de la matriz de almacenamiento, que se establece en System Manager.


.Acerca de esta tarea
En esta tarea, introduces la contraseña actual de una matriz de almacenamiento para que puedas acceder a ella en Unified Manager. Esto puede ser necesario si la contraseña de la matriz se cambió en System Manager y ahora también debe cambiarse en Unified Manager.

.Pasos
. Desde la página Manage, selecciona una o más matrices de almacenamiento.
. Selecciona el menú:Tareas no habituales[Proporcionar contraseñas de matrices de almacenamiento].
. Ingresa la contraseña o contraseñas para cada matriz de almacenamiento y luego haz clic en *Guardar*.
