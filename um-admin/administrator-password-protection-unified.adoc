= Conoce la protección de la contraseña de administrador en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debes configurar SANtricity Unified Manager con una contraseña de administrador para protegerlo de accesos no autorizados.



[[admin-password-and-user-profiles]]
== Contraseña de administrador y perfiles de usuario

Cuando inicias Unified Manager por primera vez, se te pide que establezcas una contraseña de administrador. Cualquier usuario que tenga la contraseña de administrador puede hacer cambios de configuración en las matrices de almacenamiento.

Además de la contraseña de administrador, la interfaz de Unified Manager incluye perfiles de usuario preconfigurados con uno o más roles asignados. Para más información, consulta link:../um-certificates/how-access-management-works-unified.html["Cómo funciona la gestión de accesos"].

Los usuarios y las asignaciones no se pueden cambiar. Solo se pueden modificar las contraseñas. Para cambiar las contraseñas, consulta:

* link:change-admin-password-unified.html["Cambiar la contraseña de admin"]
* link:../um-certificates/change-passwords-unified.html["Cambiar contraseñas para perfiles de usuario locales"]




[[session-timeouts]]
== Tiempos de espera de sesión

El software te pide la contraseña solo una vez durante una sola sesión de gestión. Una sesión termina después de 30 minutos de inactividad por defecto, momento en el que tienes que ingresar la contraseña de nuevo. Si otro usuario accede al software desde otro cliente de gestión y cambia la contraseña mientras tu sesión está activa, se te pedirá la contraseña la próxima vez que intentes realizar una operación de configuración o de visualización.

Por razones de seguridad, solo puedes intentar ingresar una contraseña cinco veces antes de que el software entre en estado de "bloqueo". En este estado, el software rechaza los intentos posteriores de contraseña. Debes esperar 10 minutos para restablecer el estado "normal" antes de intentar ingresar una contraseña de nuevo.

Puedes ajustar los tiempos de espera de las sesiones o puedes desactivarlos por completo. Para más información, consulta link:manage-session-timeouts-unified.html["Gestiona los tiempos de espera de las sesiones"].
