SANtricity System Manager utiliza iconos y varios otros métodos para avisarte que existen problemas con la matriz de almacenamiento.

System Manager muestra estos iconos en varias ubicaciones.

* El área de notificaciones en la página de inicio muestra el icono de error y un mensaje.
* El icono de la página de inicio en el área de navegación muestra el icono de fallo.
* En la página Components, los gráficos de las unidades y controladores muestran el icono de error.




[[alerts-and-leds]]
== Alertas y LEDs

Además, System Manager te notifica de los problemas de otras formas.

* System Manager envía notificaciones SNMP o mensajes de error por correo electrónico.
* Se encienden los LED de Service Action Required del hardware.


Cuando recibas la notificación de un problema, usa el Recovery Guru para ayudarte a solucionarlo. Donde sea necesario, usa la documentación del hardware junto con los pasos de recuperación para reemplazar los componentes averiados.
