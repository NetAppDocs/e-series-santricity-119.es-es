= Administra la protección por contraseña en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debes configurar la matriz de almacenamiento con contraseñas para protegerla de accesos no autorizados.



== Establece y cambia contraseñas

Cuando inicias System Manager por primera vez, se te pedirá que establezcas una contraseña de administrador. Cualquier usuario que tenga la contraseña de administrador puede hacer cambios de configuración en la storage array, como agregar, cambiar o eliminar objetos o configuraciones. Para establecer la contraseña de administrador durante el inicio inicial, consulta link:../san-getstarted/access-sam.html["Accede a System Manager"].

Por razones de seguridad, solo puedes intentar ingresar una contraseña cinco veces antes de que la matriz de almacenamiento entre en un estado de "bloqueo". En este estado, la matriz de almacenamiento rechazará los intentos posteriores de contraseña. Debes esperar 10 minutos para que la matriz de almacenamiento se restablezca a un estado "normal" antes de intentar ingresar una contraseña de nuevo.

Además de la contraseña de administrador, la matriz de almacenamiento incluye perfiles de usuario predefinidos con uno o más roles asignados a ellos. Para más información, consulta link:../sm-settings/permissions-for-mapped-roles.html["Permisos para roles asignados"]. Los perfiles de usuario y las asignaciones no se pueden cambiar. Solo se pueden modificar las contraseñas. Si quieres cambiar la contraseña de admin u otras contraseñas de usuario, consulta link:../sm-settings/change-passwords.html["Cambiar contraseñas"].



== Vuelve a introducir las contraseñas después de los tiempos de espera de la sesión

El sistema te pide la contraseña solo una vez durante una sesión de gestión. Sin embargo, una sesión tiene un tiempo de espera después de 30 minutos de inactividad, momento en el que tienes que ingresar la contraseña de nuevo. Si otro usuario que está gestionando la misma matriz de almacenamiento desde otro cliente de gestión cambia la contraseña mientras tu sesión está activa, se te pedirá la contraseña la próxima vez que intentes realizar una operación de configuración o de visualización.

Puedes ajustar el tiempo de espera de la sesión o puedes desactivar por completo los tiempos de espera de la sesión. Consulta link:../sm-settings/manage-session-timeouts-sam.html["Gestiona los tiempos de espera de las sesiones"].



== Eliminar unidades o protección por contraseña

Si eliminas las unidades protegidas por contraseña o quieres desactivar la protección por contraseña, ten en cuenta lo siguiente:

* *Si retiras unidades con protección por contraseña* -- La contraseña se almacena en un área reservada de cada unidad en la matriz de almacenamiento. Si retiras todas las unidades de una matriz de almacenamiento, su contraseña ya no funcionará. Para corregir esta condición, vuelve a instalar una de las unidades originales en la matriz de almacenamiento.
* *Si quieres eliminar la protección por contraseña* -- Si ya no quieres que los comandos estén protegidos por contraseña, introduce la contraseña de administrador actual y deja en blanco los cuadros de texto de la nueva contraseña.


[CAUTION]
====
La ejecución de comandos de configuración en una matriz de almacenamiento puede causar daños graves, incluida la pérdida de datos. Por esta razón, siempre deberías establecer una contraseña de administrador para tu matriz de almacenamiento. Usa una contraseña de administrador larga con al menos 15 caracteres alfanuméricos para aumentar la seguridad.
