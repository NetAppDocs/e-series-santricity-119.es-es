= Configura los puertos NVMe sobre RoCE en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si tu controlador incluye una conexión para NVMe sobre RoCE (RDMA sobre Ethernet convergente), puedes configurar los ajustes del puerto NVMe desde la página Hardware.

.Antes de empezar
* Tu controlador debe incluir un puerto de host NVMe sobre RoCE; de lo contrario, la configuración de NVMe sobre RoCE no está disponible en System Manager.
* Se debe conocer la dirección IP de la conexión de host.


.Pasos
. Selecciona *Hardware*.
. Si el gráfico muestra las unidades, haz clic en la pestaña *Controladores y componentes*.
+
El gráfico cambia para mostrar los controladores en lugar de las unidades.

. Haz clic en el controlador con el puerto NVMe sobre RoCE que quieres configurar.
+
Aparece el menú contextual de la controladora.

. Selecciona *Configurar puertos NVMe sobre RoCE*.
+
Se abre el cuadro de diálogo Configurar puertos NVMe sobre RoCE.

. En la lista desplegable, selecciona el puerto HIC que quieres configurar.
. Haz clic en *Siguiente*.
+
Para ver todos los ajustes del puerto, haz clic en el enlace *Mostrar más ajustes del puerto* a la derecha del cuadro de diálogo.

+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Opción de configuración de puertos | Descripción 


 a| 
Velocidad de puerto Ethernet configurada
 a| 
Seleccione la velocidad que coincida que la capacidad de velocidad del SFP en el puerto.



 a| 
Habilitar IPv4/Habilitar IPv6
 a| 
Selecciona una o ambas opciones para activar la compatibilidad con redes IPv4 e IPv6.


NOTE: Si desea deshabilitar el acceso al puerto, cancele la selección de las dos casillas de comprobación.



 a| 
Tamaño de MTU (disponible haciendo clic en *Mostrar más ajustes de puerto*.)
 a| 
Si es necesario, ingresa un nuevo tamaño en bytes para la Unidad de Transmisión Máxima (MTU).

El tamaño por defecto de la Unidad de Transmisión Máxima (MTU) es de 1500 bytes por trama. Tienes que ingresar un valor entre 1500 y 9000.

|===
====
+
Si seleccionaste *Enable IPv4*, se abre un cuadro de diálogo para elegir la configuración de IPv4 después de que hagas clic en *Next*. Si seleccionaste *Enable IPv6*, se abre un cuadro de diálogo para elegir la configuración de IPv6 después de que hagas clic en *Next*. Si seleccionaste ambas opciones, primero se abre el cuadro de diálogo para la configuración de IPv4 y luego, después de hacer clic en *Next*, se abre el cuadro de diálogo para la configuración de IPv6.

. Configure los valores para IPv4 o IPv6 de forma automática o manual.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Opción de configuración de puertos | Descripción 


 a| 
Obtener configuración automáticamente
 a| 
Seleccione esta opción para obtener automáticamente la configuración.



 a| 
Especificar manualmente la configuración estática
 a| 
Selecciona esta opción y luego introduce una dirección estática en los campos. (Si quieres, puedes cortar y pegar direcciones en los campos.) Para IPv4, incluye la máscara de subred y la puerta de enlace. Para IPv6, incluye la dirección IP enrutable y la dirección IP del router. Si estás configurando una EF600 storage array con un HIC de 200Gb, este cuadro de diálogo muestra dos conjuntos de campos para parámetros de red: uno para un puerto físico (externo) y otro para un puerto virtual (interno). Deberías asignar parámetros únicos para ambos puertos. Estos ajustes permiten que el host establezca una ruta entre cada puerto y que el HIC logre el máximo rendimiento. Si no asignas una dirección IP al puerto virtual, el HIC funcionará aproximadamente a la mitad de su velocidad máxima.

|===
====
. Haz clic en *Finalizar*.
