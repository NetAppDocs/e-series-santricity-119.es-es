= Configura el puerto de gestión en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El controlador incluye un puerto Ethernet utilizado para la administración de sistemas. Si es necesario, puedes cambiar sus parámetros de transmisión y direcciones IP.

.Acerca de esta tarea
Durante este procedimiento, seleccionas el puerto 1 y luego determinas la velocidad y el método de direccionamiento del puerto. El puerto 1 se conecta a la red donde el cliente de gestión puede acceder al controlador y System Manager.

[NOTE]
====
No uses el puerto 2 en ninguno de los controladores. El puerto 2 está reservado para uso de soporte técnico.

====
.Pasos
. Selecciona *Hardware*.
. Si el gráfico muestra las unidades, haz clic en la pestaña *Controladores y componentes*.
+
El gráfico cambia para mostrar los controladores en lugar de las unidades.

. Haz clic en el controlador con el puerto de gestión que quieres configurar.
+
Aparece el menú contextual de la controladora.

. Selecciona *Configurar puertos de gestión*.
+
Se abre el cuadro de diálogo Configure Management Ports.

. Asegúrate de que se muestra el puerto 1 y luego haz clic en *Siguiente*.
. Selecciona los ajustes del puerto de configuración y luego haz clic en *Siguiente*.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Campo | Descripción 


 a| 
Velocidad y modo doble
 a| 
Mantén el ajuste Auto-negotiate si quieres que System Manager determine los parámetros de transmisión entre la matriz de almacenamiento y la red, o si sabes la velocidad y el modo de tu red, selecciona los parámetros en la lista desplegable. Solo aparecen en la lista las combinaciones válidas de velocidad y modo doble.



 a| 
Habilitar IPv4/Habilitar IPv6
 a| 
Selecciona una o ambas opciones para activar la compatibilidad con redes IPv4 e IPv6.

|===
====
+
Si seleccionas *Enable IPv4*, se abre un cuadro de diálogo para elegir la configuración de IPv4 después de que hagas clic en *Next*. Si seleccionas *Enable IPv6*, se abre un cuadro de diálogo para elegir la configuración de IPv6 después de que hagas clic en *Next*. Si seleccionas ambas opciones, primero se abre el cuadro de diálogo para la configuración de IPv4 y luego, después de que hagas clic en *Next*, se abre el cuadro de diálogo para la configuración de IPv6.

. Configure los valores para IPv4 o IPv6 de forma automática o manual.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Campo | Descripción 


 a| 
Obtener la configuración automáticamente desde el servidor DHCP
 a| 
Seleccione esta opción para obtener automáticamente la configuración.



 a| 
Especificar manualmente la configuración estática
 a| 
Selecciona esta opción y luego ingresa la dirección IP del controlador. (Si quieres, puedes cortar y pegar direcciones en los campos.) Para IPv4, incluye la máscara de subred y la puerta de enlace. Para IPv6, incluye la dirección IP enrutable y la dirección IP del router.


NOTE: Si cambias la configuración de la dirección IP, pierdes la ruta de administración a la matriz de almacenamiento. Si usas SANtricity Unified Manager para gestionar globalmente las matrices en tu red, abre la interfaz de usuario y ve a menu:Manage[Discover]. Si usas SANtricity Storage Manager, tienes que quitar el dispositivo de la Enterprise Management Window (EMW), volver a agregarlo a la EMW seleccionando menu:Edit[Add Storage Array] y luego ingresar la nueva dirección IP.

|===
====
. Haz clic en *Finalizar*.


.Resultados
La configuración del puerto de gestión se muestra en la configuración del controlador, pestaña Puertos de gestión.
