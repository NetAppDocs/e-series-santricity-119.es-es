= Ver la configuración del controlador en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes ver información sobre un controlador, como el estado de las interfaces del host, las interfaces de unidades y los puertos de gestión.

.Pasos
. Selecciona *Hardware*.
. Si el gráfico muestra las unidades, haz clic en la pestaña *Controladores y componentes*.
+
El gráfico cambia para mostrar los controladores en lugar de las unidades.

. Haz una de las siguientes acciones para mostrar la configuración del controlador:
+
** Haz clic en el controlador para mostrar el menú contextual y luego selecciona *Ver configuración*.
** Selecciona el icono del controlador (junto a la lista desplegable *Shelf*). Para configuraciones dúplex, selecciona *Controller A* o *Controller B* en el cuadro de diálogo y luego haz clic en *Next*.
+
Se abre el cuadro de diálogo Controller Settings.



. Selecciona las pestañas para moverte entre la configuración de las propiedades.
+
Algunas pestañas tienen un enlace para *Mostrar más ajustes* en la parte superior derecha.

+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Pestaña | Descripción 


 a| 
Base
 a| 
Muestra el estado del controlador, el nombre del modelo, el número de pieza de repuesto, la versión actual del firmware y la versión de la memoria estática no volátil de acceso aleatorio (NVSRAM).



 a| 
Caché
 a| 
Muestra la configuración de la caché del controlador, que incluye la caché de datos, la caché del procesador y el dispositivo de copia de seguridad de la caché. El dispositivo de copia de seguridad de la caché se usa para hacer una copia de seguridad de los datos en la caché si pierdes la alimentación del controlador. El estado puede ser Óptimo, Fallido, Eliminado, Desconocido, Protegido contra escritura o Incompatible.



 a| 
Interfaces del host
 a| 
Muestra la información de la interfaz del host y el estado de enlace de cada puerto. La interfaz del host es la conexión entre el controlador y el host, como Fibre Channel o iSCSI.


NOTE: La ubicación de la tarjeta de interfaz del host (HIC) puede ser en la placa base o en una ranura (bahía). "Placa base" indica que los puertos HIC están integrados en el controlador. "Ranura" indica que los puertos están en la HIC opcional.



 a| 
Interfaces de unidad
 a| 
Muestra la información de la interfaz de la unidad y el estado del enlace de cada puerto. La interfaz de la unidad es la conexión entre el controlador y las unidades, como SAS.



 a| 
Puertos de gestión
 a| 
Muestra los detalles del puerto de gestión, como el nombre de host usado para acceder al controlador y si se ha habilitado un inicio de sesión remoto. El puerto de gestión conecta el controlador y el cliente de gestión, que es donde se instala un navegador para acceder a System Manager.



 a| 
DNS / NTP
 a| 
Muestra el método de direccionamiento y las direcciones IP para el servidor DNS y el servidor NTP, si estos servidores se han configurado en System Manager.

El Sistema de Nombres de Dominio (DNS) es un sistema de nomenclatura para dispositivos conectados a Internet o a una red privada. El servidor DNS mantiene un directorio de nombres de dominio y los traduce a direcciones de Protocolo de Internet (IP).

Network Time Protocol (NTP) es un protocolo de red para la sincronización del reloj entre sistemas informáticos en redes de datos.

|===
====
. Haz clic en *Cerrar*.
