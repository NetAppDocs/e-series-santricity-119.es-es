= Configura las direcciones del servidor DNS en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Domain Name System (DNS) se usa para resolver nombres de dominio completos para los controladores y un servidor NTP. Los puertos de administración de la matriz de almacenamiento pueden admitir protocolos IPv4 o IPv6 simultáneamente.

.Antes de empezar
* Debes instalar y configurar un servidor DNS en tu red.
* Tú sabes la dirección del servidor DNS primario y de un servidor DNS de respaldo opcional. Estas direcciones pueden ser direcciones IPv4 o direcciones IPv6.


.Acerca de esta tarea
Este procedimiento describe cómo especificar una dirección de servidor DNS primario y de respaldo. El servidor DNS de respaldo se puede configurar opcionalmente para usarlo si falla un servidor DNS primario.

[NOTE]
====
Si ya configuraste los puertos de administración de la matriz de almacenamiento con Dynamic Host Configuration Protocol (DHCP), y tienes uno o más servidores DNS o NTP asociados con la configuración de DHCP, entonces no necesitas configurar manualmente DNS o NTP. En este caso, la matriz de almacenamiento ya debería haber obtenido automáticamente las direcciones de los servidores DNS/NTP. Sin embargo, igual deberías seguir las instrucciones de abajo para abrir el cuadro de diálogo y asegurarte de que se detectan las direcciones correctas.

====
.Pasos
. Selecciona *Hardware*.
. Si el gráfico muestra las unidades, haz clic en la pestaña *Controladores y componentes*.
+
El gráfico cambia para mostrar los controladores en lugar de las unidades.

. Selecciona el controlador que quieres configurar.
+
Aparece el menú contextual de la controladora.

. Selecciona *Configurar servidor DNS*.
+
Se abre el cuadro de diálogo Configure Domain Name System (DNS) Server.

. Selecciona una de las siguientes opciones:
+
** *Obtener automáticamente las direcciones del servidor DNS del servidor DHCP* -- Se muestran las direcciones del servidor DNS detectadas.
+
[NOTE]
====
Si la matriz de almacenamiento está configurada para usar una dirección DNS estática, no aparecen servidores DNS.

====
** *Especifica manualmente las direcciones del servidor DNS* -- Ingresa una dirección de servidor DNS principal y una dirección de servidor DNS de respaldo. El servidor de respaldo es opcional. (Estos campos de dirección aparecen después de que selecciones el botón de opción.) Estas direcciones pueden ser direcciones IPv4 o direcciones IPv6.


. Haz clic en *Guardar*.
. Repite estos pasos para el otro controlador.


.Resultados
La configuración de DNS se muestra en los ajustes del controlador, pestaña *DNS / NTP*.
