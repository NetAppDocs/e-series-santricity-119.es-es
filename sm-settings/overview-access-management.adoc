= Conoce la gestión de control de acceso en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Access Management es un método para establecer la autenticación de usuario en SANtricity System Manager.



== ¿Qué métodos de autenticación están disponibles?

Los métodos de autenticación incluyen RBAC (control de acceso basado en roles), Directory Services y Security Assertion Markup Language (SAML):

* *RBAC/Roles de usuario locales* -- La autenticación se gestiona mediante capacidades RBAC aplicadas en la matriz de almacenamiento. Los roles de usuario locales incluyen perfiles de usuario predefinidos y roles con permisos de acceso específicos.
* *Servicios de directorio* -- La autenticación se gestiona a través de un servidor LDAP (Lightweight Directory Access Protocol) y Directory Services, como Active Directory de Microsoft.
* *SAML* -- La autenticación se gestiona a través de un Identity Provider (IdP) usando SAML 2.0.

== ¿Cómo configuro la autenticación?

La matriz de almacenamiento está preconfigurada para utilizar roles de usuario locales, que son una implementación de las capacidades RBAC. Si quieres configurar un método diferente, ve al menú:Settings[Access Management].
