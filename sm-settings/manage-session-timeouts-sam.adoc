= Gestiona los tiempos de espera de sesión en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes configurar tiempos de espera en SANtricity System Manager para que las sesiones inactivas de los usuarios se desconecten después de un tiempo especificado.

.Acerca de esta tarea
Por defecto, el tiempo de espera de sesión para System Manager es de 30 minutos. Puedes ajustar ese tiempo o también puedes desactivar por completo los tiempos de espera de sesión.

[NOTE]
====
Si Access Management se configura usando las capacidades de Security Assertion Markup Language (SAML) integradas en la cabina, podría ocurrir un tiempo de espera de la sesión cuando la sesión de SSO del usuario llegue a su límite máximo. Esto podría ocurrir antes del tiempo de espera de la sesión de System Manager.

====
.Pasos
. Selecciona menú:ajustes[Sistema].
. En la sección General, selecciona *Activar/Desactivar tiempo de espera de sesión*.
+
Se abre el cuadro de diálogo Enable/Disable Session Timeout.

. Usa los mandos giratorios para aumentar o disminuir el tiempo en minutos.
+
El tiempo de espera mínimo que puedes establecer para System Manager es de 15 minutos.

+
[NOTE]
====
Para desactivar los tiempos de espera de la sesión, desmarca la casilla *Establece la duración del tiempo...*.

====
. Haz clic en *Guardar*.
