= Configura los informes de conectividad de host en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes activar los informes de conectividad de host para que la matriz de almacenamiento supervise continuamente la conexión entre los controladores y los hosts configurados, y luego te avise si se interrumpe la conexión. Esta función está activada de forma predeterminada.

.Acerca de esta tarea
Si desactivas los informes de conectividad de host, el sistema ya no supervisa la conectividad ni los problemas de controladores multivía con un host conectado a la matriz de almacenamiento.

[NOTE]
====
Desactivar los informes de conectividad de host también desactiva el equilibrio de carga automático, que supervisa y equilibra la utilización de los recursos del controlador.

====
.Pasos
. Selecciona menú:ajustes[Sistema].
. Desplázate hacia abajo hasta *Configuración adicional* y luego haz clic en *Activar/desactivar informes de conectividad de host*.
+
El texto debajo de esta opción indica si está habilitada o deshabilitada.

+
Se abre un cuadro de diálogo de confirmación.

. Haz clic en *Sí* para continuar.
+
Al seleccionar esta opción, alternas la función entre activada y desactivada.
