[[how-do-i-interpret-nvme-over-fabrics-statistics]]
== ¿Cómo interpreto las estadísticas de NVMe over Fabrics?

El cuadro de diálogo View NVMe over Fabrics Statistics muestra estadísticas para el subsistema NVMe y la interfaz RDMA. Todas las estadísticas son de solo lectura y no se pueden configurar.

* *Estadísticas del subsistema NVMe* -- Muestra estadísticas para el controlador NVMe y su cola. El controlador NVMe proporciona una ruta de acceso entre un host y los namespaces en la matriz de almacenamiento. Puedes revisar las estadísticas del subsistema NVMe para elementos como fallos de conexión, reinicios y apagados. Para más información sobre estas estadísticas, haz clic en *Ver leyenda de los encabezados de la tabla*.
* *RDMA Interface statistics* -- Proporciona estadísticas para todos los puertos NVMe over Fabrics en la interfaz RDMA, que incluye estadísticas de rendimiento e información de errores de enlace asociada a cada puerto del switch. Esta pestaña solo aparece cuando los puertos NVMe over Fabrics están disponibles. Para más información sobre las estadísticas, haz clic en *View legend for table headings*.


Puedes ver cada una de estas estadísticas como estadísticas sin procesar o como estadísticas de línea de base. Las estadísticas sin procesar son todas las estadísticas que se han recopilado desde que se iniciaron los controladores. Las estadísticas de línea de base son estadísticas de un momento específico que se han recopilado desde que estableciste la hora de línea de base.

[[why-are-there-two-ip-addresses-for-one-physical-port]]
== ¿Por qué hay dos direcciones IP para un puerto físico?

La matriz de almacenamiento EF600 puede incluir dos HICs: uno externo y uno interno.

En esta configuración, el HIC externo está conectado a un HIC interno auxiliar. Cada puerto físico al que puedes acceder desde el HIC externo tiene un puerto virtual asociado del HIC interno.

Para conseguir el máximo rendimiento de 200 Gb, debes asignar una dirección IP única tanto para el puerto físico como para el virtual, así el host puede establecer conexiones con cada uno. Si no asignas una dirección IP al puerto virtual, el HIC funcionará aproximadamente a la mitad de su velocidad máxima.



[[why-are-there-two-sets-of-parameters-for-one-physical-port]]
== ¿Por qué hay dos conjuntos de parámetros para un puerto físico?

La matriz de almacenamiento EF600 puede incluir dos HICs: uno externo y uno interno.

En esta configuración, el HIC externo está conectado a un HIC interno auxiliar. Cada puerto físico al que puedes acceder desde el HIC externo tiene un puerto virtual asociado del HIC interno.

Para conseguir el máximo rendimiento de 200 Gb, debes asignar parámetros tanto a los puertos físicos como a los virtuales para que el host pueda establecer conexiones con cada uno. Si no asignas parámetros al puerto virtual, el HIC funcionará aproximadamente a la mitad de su velocidad máxima.
