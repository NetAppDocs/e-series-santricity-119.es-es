[role="lead"]
Puedes configurar SANtricity System Manager para enviar alertas de la matriz de almacenamiento por correo electrónico, traps SNMP y mensajes syslog.



[[what-are-alerts]]
== ¿Qué son las alertas?

_Alertas_ notifican a los administradores sobre eventos importantes que ocurren en la matriz de almacenamiento. Los eventos pueden incluir problemas como una falla de la batería, un componente que pasa de óptimo a fuera de línea o errores de redundancia en el controlador. Todos los eventos críticos se consideran "alertables", junto con algunos eventos de advertencia e informativos.

Más información:

* link:how-alerts-work.html["¿Cómo funcionan las alertas?"]
* link:alerts-terminology.html["Terminología de alertas"]




[[how-do-i-configure-alerts]]
== ¿Cómo configuro alertas?

Puedes configurar las alertas para que se envíen como mensaje a una o varias direcciones de correo electrónico, como trampa SNMP a un servidor SNMP o como mensaje a un servidor syslog. La configuración de alertas está disponible desde menú:Settings[Alerts].
