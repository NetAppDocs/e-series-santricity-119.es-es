= Borrar la configuración de la matriz de almacenamiento en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Usa la operación Clear Configuration cuando quieras borrar todos los pools, grupos de volúmenes, volúmenes, definiciones de host y asignaciones de host del storage array.

.Antes de empezar
Antes de borrar la configuración de la matriz de almacenamiento, haz una copia de seguridad de los datos.

.Acerca de esta tarea
Hay dos opciones de Clear Storage Array Configuration:

* *Volumen* -- Normalmente, podrías usar la opción Volumen para reconfigurar una matriz de almacenamiento de prueba como una matriz de almacenamiento de producción. Por ejemplo, podrías configurar una matriz de almacenamiento para pruebas y luego, cuando termines de probar, eliminar la configuración de prueba y configurar la matriz de almacenamiento para un entorno de producción.
* *Storage Array* -- Normalmente, podrías usar la opción Storage Array para mover una matriz de almacenamiento a otro departamento o grupo. Por ejemplo, podrías estar usando una matriz de almacenamiento en Ingeniería, y ahora Ingeniería va a recibir una nueva matriz de almacenamiento, así que quieres mover la matriz de almacenamiento actual a Administración, donde se va a reconfigurar.
+
La opción Storage Array elimina algunas configuraciones adicionales.

[CAUTION]
====
*Riesgo de pérdida de datos* -- Esta operación borra todos los datos de tu matriz de almacenamiento. (No realiza un borrado seguro.) No puedes cancelar esta operación después de que haya comenzado. Realiza esta operación solo cuando te lo indique soporte técnico.

====
.Pasos
. Selecciona menú:ajustes[Sistema].
. Selecciona *Borrar configuración de matriz de almacenamiento*.
. En la lista desplegable, selecciona *Volumen* o *Matriz de almacenamiento*.
. *Opcional:* Si quieres guardar la configuración (no los datos), usa los enlaces en el cuadro de diálogo.
. Confirma que quieres realizar la operación.


.Resultados
* Se borra la configuración actual, lo que destruye todos los datos existentes en la matriz de almacenamiento.
* Todas las unidades están sin asignar.
+

NOTE: La matriz de almacenamiento se iniciará en modo de recuperación. Debes desactivar el modo de recuperación antes de usar la matriz de almacenamiento. Consulta https://docs.netapp.com/us-en/e-series-santricity/sm-support/clear-recovery-mode.html["Borrar el modo de recuperación"^] para más información.
