= Crear tokens de acceso en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes crear un token de acceso para autenticarte con la API de REST o la interfaz de línea de comandos (CLI) en lugar de un nombre de usuario y una contraseña.


NOTE: Los tokens no tienen contraseñas, así que debes gestionarlos con cuidado.

.Pasos
. Selecciona el menú:Configuración[Gestión de acceso].
. Selecciona la pestaña *Access Tokens*.
. Selecciona *View/Edit Access Token Settings*. En el cuadro de diálogo, asegúrate de que la casilla *Enable access tokens* esté seleccionada. Haz clic en *Save* para cerrar el cuadro de diálogo.
. Selecciona *Create Access Token*.
. En el cuadro de diálogo, selecciona la duración para que el token sea válido.
+

NOTE: Después de que el token caduque, los intentos de autenticación del usuario fallarán.

. Haz clic en *Crear.*
. En el cuadro de diálogo, selecciona una de las siguientes opciones:
+
** *Copiar* para guardar el texto del token en el portapapeles.
** *Descargar* para guardar el texto del token en un archivo.
+

NOTE: Asegúrate de guardar el texto del token. Esta es tu única oportunidad de ver el texto antes de cerrar el diálogo.



. Haz clic en *Cerrar*.
. Utiliza el token como se indica a continuación:
+
** *API de REST*: Para usar un token en una solicitud de API de REST, agrega un encabezado HTTP a tus solicitudes. Por ejemplo:
`Authorization: Bearer _<access-token-value>_`
** *CLI segura*: Para usar un token en la CLI, agrega el valor del token en la línea de comandos o usa la ruta a un archivo que contenga el valor del token. Por ejemplo:
+
*** Valor del token en la línea de comandos: `-t _access-token-value_`
*** Ruta a un archivo que contiene el valor del token: `-T _access-token-file_`
+

NOTE: La CLI solicita al usuario un valor de token de acceso en la línea de comandos si no se especifica ningún nombre de usuario, contraseña o token.
