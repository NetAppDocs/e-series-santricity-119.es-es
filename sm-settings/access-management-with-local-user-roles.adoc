= Configura la gestión de acceso con roles de usuario locales en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para Access Management, los administradores pueden usar las capacidades de RBAC (control de acceso basado en roles) aplicadas en la matriz de almacenamiento. Estas capacidades se conocen como "local user roles".



== Flujo de trabajo de configuración

Los roles de usuario locales están preconfigurados para la storage array. Para usar roles de usuario locales para la autenticación, los administradores pueden hacer lo siguiente:

. Un administrador inicia sesión en System Manager con un perfil de usuario que incluye permisos de Security Admin.
+
[NOTE]
====
El `admin` usuario tiene acceso completo a todas las funciones del sistema.

====
. Un administrador revisa los perfiles de usuario, que están predefinidos y no pueden modificarse.
. Opcionalmente, el administrador asigna nuevas contraseñas para cada perfil de usuario.
. Los usuarios inician sesión en el sistema con sus credenciales asignadas.




== Gestión

Cuando usas solo roles de usuario locales para la autenticación, los administradores pueden realizar las siguientes tareas de gestión:

* Cambia las contraseñas.
* Establece una longitud mínima para las contraseñas.
* Permite que los usuarios inicien sesión sin contraseñas.
