= Importar la configuración de servicios de directorio en SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible importar la configuración de los servicios de directorio desde una cabina de almacenamiento a otras cabinas de almacenamiento. Esta operación en lote permite ahorrar tiempo cuando se necesitan configurar varias matrices en la red.

.Antes de empezar
* Los servicios de directorio se configuran en System Manager para la matriz de almacenamiento que quieres usar como origen (menú:Settings[Access Management]).
* La configuración existente para las matrices de almacenamiento de destino se respalda en System Manager (menú:Settings[System > Save Storage Array Configuration]).


.Acerca de esta tarea
La configuración importada incluye el nombre de dominio y la URL de un servidor LDAP (protocolo ligero de acceso a directorios), junto con las asignaciones de los grupos de usuarios del servidor LDAP con los roles predefinidos de la cabina de almacenamiento.

.Pasos
. Desde la página Manage, haz clic en *Import Settings*.
+
Se abre el asistente Importar configuración.

. En el cuadro de diálogo Seleccionar configuración, selecciona *Servicios de directorio* y luego haz clic en *Siguiente*.
+
Se abre un cuadro de diálogo para seleccionar la cabina de almacenamiento.

. En el cuadro de diálogo Seleccionar origen, selecciona la matriz con la configuración que quieres importar y luego haz clic en *Siguiente*.
. En el cuadro de diálogo Seleccionar objetivos, selecciona una o varias matrices para recibir la nueva configuración.
+
[NOTE]
====
Las matrices de almacenamiento con firmware inferior a 8.50 no están disponibles para selección. Además, una matriz no aparece en este cuadro de diálogo si Unified Manager no puede comunicarse con esa matriz (por ejemplo, si está desconectada o si tiene problemas de certificado, contraseña o red).

====
. Haz clic en *Finalizar*.
+
La página Operaciones muestra los resultados de la operación de importación. Si la operación falla, puedes hacer clic en su fila para ver más información.





[[results]]
== Resultados

Las cabinas de almacenamiento objetivo ahora están configuradas con los mismos servicios de directorio que la cabina de origen.
