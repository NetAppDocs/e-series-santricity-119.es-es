= Conoce la detección en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para gestionar los recursos de almacenamiento, primero tienes que descubrir las cabinas de almacenamiento en la red.



[[how-do-i-discover-arrays]]
== ¿Cómo descubro las matrices?

Usa la página Add/Discover para buscar y agregar las matrices de almacenamiento que quieres gestionar en la red de tu organización. Puedes descubrir varias matrices o puedes descubrir una sola matriz. Para hacer esto, introduces direcciones IP de red y luego Unified Manager intenta conexiones individuales con cada dirección IP de ese rango.

Más información:

* link:considerations-for-discovering-arrays.html["Consideraciones sobre la detección de cabinas"]
* link:discover-multiple-arrays.html["Descubre varias cabinas de almacenamiento"]
* link:discover-single-array.html["Descubrir una sola matriz"]




[[how-do-i-manage-arrays]]
== ¿Cómo gestiono las matrices?

Después de descubrir las matrices, ve a la página *Manage - All*. Desde esta página, puedes desplazarte por una lista de matrices de almacenamiento descubiertas en tu red, ver su estado y realizar operaciones en una sola matriz o en un grupo de matrices.

Si quieres gestionar una sola matriz, puedes seleccionarla y abrir System Manager.

Más información:

* link:launch-considerations.html["Consideraciones para acceder a System Manager"]
* link:launch-system-manager.html["Gestionar una cabina de almacenamiento individual"]
* link:storage-array-status.html["Ver el estado de la matriz de almacenamiento"]
