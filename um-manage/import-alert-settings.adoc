= Importar la configuración de alertas en SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible importar la configuración de alerta de una cabina de almacenamiento en otras cabinas de almacenamiento. Esta operación en lote permite ahorrar tiempo cuando se necesitan configurar varias matrices en la red.

.Antes de empezar
* Las alertas se configuran en System Manager para la matriz de almacenamiento que quieres usar como origen (menu:Settings[Alerts]).
* La configuración existente para las matrices de almacenamiento de destino se respalda en System Manager (menú:Settings[System > Save Storage Array Configuration]).


.Acerca de esta tarea
Puede seleccionar las opciones de correo electrónico, SNMP o alertas de syslog para la operación de importación. La configuración importada incluye lo siguiente:

* *Alertas por correo electrónico* -- Una dirección de servidor de correo y las direcciones de correo electrónico de los destinatarios de alertas.
* *Alertas syslog* -- una dirección de servidor syslog y un puerto UDP.
* *SNMP alerts* -- Un nombre de comunidad y una dirección IP para el servidor SNMP.


.Pasos
. Desde la página Manage, haz clic en *Import Settings*.
+
Se abre el asistente Importar configuración.

. En el cuadro de diálogo Seleccionar configuración, selecciona *Alertas de correo electrónico*, *Alertas de SNMP* o *Alertas de syslog* y luego haz clic en *Siguiente*.
+
Se abre un cuadro de diálogo para seleccionar la cabina de almacenamiento.

. En el cuadro de diálogo Seleccionar origen, selecciona la matriz con la configuración que quieres importar y luego haz clic en *Siguiente*.
. En el cuadro de diálogo Seleccionar objetivos, selecciona una o varias matrices para recibir la nueva configuración.
+
[NOTE]
====
Las matrices de almacenamiento con firmware inferior a 8.50 no están disponibles para selección. Además, una matriz no aparece en este cuadro de diálogo si Unified Manager no puede comunicarse con esa matriz (por ejemplo, si está desconectada o si tiene problemas de certificado, contraseña o red).

====
. Haz clic en *Finalizar*.
+
La página Operaciones muestra los resultados de la operación de importación. Si la operación falla, puedes hacer clic en su fila para ver más información.



.Resultados
Las cabinas de almacenamiento objetivo ahora están configuradas para enviar alertas a los administradores mediante correo electrónico, SNMP o syslog.
