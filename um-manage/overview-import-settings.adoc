= Conoce cómo importar configuraciones de matrices de almacenamiento en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La función Import Settings permite realizar una operación por lotes para importar la configuración de una matriz a varias matrices. Esta función ahorra tiempo cuando necesitas configurar varias matrices en la red.



[[what-settings-can-be-imported]]
== ¿Qué ajustes se pueden importar?

Puedes importar métodos de alerta, configuraciones de AutoSupport, configuraciones de Servicios de directorio, configuraciones de almacenamiento (como grupos de volúmenes y pools) y configuraciones del sistema (como el equilibrio de carga automático).

Más información:

* link:how-import-settings-works.html["Cómo funciona la importación de configuración"]
* link:requirements-for-replicating-storage-configurations.html["Requisitos para replicar configuraciones de almacenamiento"]




[[how-do-i-perform-a-batch-import]]
== ¿Cómo hago una importación por lotes?

En una matriz de almacenamiento que se vaya a usar como origen, abre System Manager y configura los ajustes deseados. Luego, desde Unified Manager, ve a la página Manage e importa los ajustes a una o más matrices.
