= Conoce cómo configurar varias cabinas de almacenamiento en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes usar SANtricity Unified Manager para importar configuraciones de una matriz de almacenamiento a varias matrices de almacenamiento. La función Import Settings es una operación por lotes que ahorra tiempo cuando necesitas configurar varias matrices en la red.



[[settings-available-for-import]]
== Configuración disponible para la importación

Las siguientes configuraciones pueden importarse a varias arrays:

* *Alertas* -- Métodos de alerta para enviar eventos importantes a los administradores, usando correo electrónico, un servidor syslog o un servidor SNMP.
* *AutoSupport* -- una función que supervisa el estado de una matriz de almacenamiento y envía despachos automáticos al soporte técnico.
* *Servicios de directorio* -- Un método de autenticación de usuarios que se gestiona a través de un servidor LDAP (Lightweight Directory Access Protocol) y un servicio de directorio, como Microsoft Active Directory.
* *Configuración de almacenamiento* -- Configuraciones relacionadas con lo siguiente:
+
** Volúmenes (solo volúmenes gruesos y que no pertenecen al repositorio)
** Grupos de volúmenes y pools
** Asignaciones de unidad de repuesto


* *Ajustes del sistema* -- Configuraciones relacionadas con lo siguiente:
+
** Configuración de escaneo de medios para un volumen
** Configuración de SSD
** Equilibrio de carga automático (no incluye la generación de informes de conectividad de host)






[[configuration-workflow]]
== Flujo de trabajo de configuración

Para importar la configuración, siga este flujo de trabajo:

. En una matriz de almacenamiento que se vaya a utilizar como origen, configura los ajustes usando System Manager.
. En las matrices de almacenamiento que se usarán como destinos, haz una copia de seguridad de su configuración usando System Manager.
. Desde Unified Manager, ve a la página *Manage* e importa la configuración.
. Desde la página *Operaciones*, revisa los resultados de la operación Importar configuración.
