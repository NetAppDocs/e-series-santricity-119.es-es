= Requisitos para replicar configuraciones de almacenamiento en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de importar una configuración de almacenamiento de una matriz de almacenamiento a otra, revisa los requisitos y directrices.



== Bandejas

* Los estantes donde residen los controladores deben ser idénticos en los arrays de origen y destino.
* Los ID de bandeja deben ser idénticos en las cabinas de origen y objetivo.
* Las bandejas de expansión deben colocarse en las mismas ranuras con los mismos tipos de unidad (si la unidad se usa en la configuración, la ubicación de las unidades no utilizadas no importa).




== Controladoras

* El tipo de controlador puede ser diferente entre las matrices de origen y destino (por ejemplo, importar de un E2800 a un E5700), pero el tipo de caja RBOD debe ser idéntico.
* Los HIC, incluidas las capacidades DA del host, deben ser idénticos entre las arrays de origen y destino.
* No se admite la importación de una configuración doble a una simple; sí se admite la configuración simple a doble.
* La configuración de unidades FDE no está incluida en el proceso de importación.




== Estado

* Las cabinas objetivo deben tener el estado Óptimo.
* La cabina de origen no necesita tener el estado Óptimo.




== Almacenamiento

* La capacidad de las unidades puede variar entre las matrices de origen y de destino, siempre y cuando la capacidad del volumen en el destino sea mayor que en el origen. (Una matriz de destino podría tener unidades más nuevas y de mayor capacidad que no serían totalmente configuradas en volúmenes por la operación de replicación.)
* Los volúmenes de pool de discos de 64 TB o más en la cabina de origen impedirán el proceso de importación en los destinos.
* Los volúmenes finos no están incluidos en el proceso de importación.
