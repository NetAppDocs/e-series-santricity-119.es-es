= Importa los ajustes de configuración de almacenamiento en SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible importar la configuración de almacenamiento de una cabina de almacenamiento en otras cabinas de almacenamiento. Esta operación en lote permite ahorrar tiempo cuando se necesitan configurar varias matrices en la red.

.Antes de empezar
* El almacenamiento se configura en SANtricity System Manager para la matriz de almacenamiento que quieres usar como origen.
* La configuración existente para las matrices de almacenamiento de destino se respalda en System Manager (menú:Settings[System > Save Storage Array Configuration]).
* Las cabinas de origen y objetivo deben cumplir con los siguientes requisitos:
+
** Las bandejas donde residan las controladoras deben ser idénticas.
** Los ID de bandeja deben ser idénticos.
** Las bandejas de expansión deben llenarse en las mismas ranuras con los mismos tipos de unidad.
** El tipo de compartimento RBOD debe ser idéntico.
** Las HIC, incluidas las capacidades de garantía de datos del host, deben ser idénticas.
** Las cabinas objetivo deben tener el estado Óptimo.
** La capacidad de volumen de la cabina objetivo es mayor que la capacidad de la cabina de origen.


* Debe considerar las siguientes restricciones:
+
** No se admite la importación de una configuración doble a una simple; sí se admite la configuración simple a doble.
** Los volúmenes de pool de discos de 64 TB o más en la cabina de origen impedirán el proceso de importación en los destinos.
** Los volúmenes finos no están incluidos en el proceso de importación.




.Acerca de esta tarea
La configuración importada incluye volúmenes configurados (solo volúmenes gruesos y que no pertenecen al repositorio), grupos de volúmenes, pools y asignaciones de unidades de repuesto.

.Pasos
. Desde la página Manage, haz clic en *Import Settings*.
+
Se abre el asistente Importar configuración.

. En el cuadro de diálogo Seleccionar configuración, selecciona *Storage configuration* y luego haz clic en *Next*.
+
Se abre un cuadro de diálogo para seleccionar la cabina de almacenamiento.

. En el cuadro de diálogo Seleccionar origen, selecciona la matriz con la configuración que quieres importar y luego haz clic en *Siguiente*.
. En el cuadro de diálogo Seleccionar objetivos, selecciona una o varias matrices para recibir la nueva configuración.
+
[NOTE]
====
Las matrices de almacenamiento con firmware inferior a 8.50 no están disponibles para selección. Además, una matriz no aparece en este cuadro de diálogo si Unified Manager no puede comunicarse con esa matriz (por ejemplo, si está desconectada o si tiene problemas de certificado, contraseña o red).

====
. Haz clic en *Finalizar*.
+
La página Operaciones muestra los resultados de la operación de importación. Si la operación falla, puedes hacer clic en su fila para ver más información.



.Resultados
Las cabinas de almacenamiento objetivo ahora están configuradas con los mismos ajustes de almacenamiento que la cabina de origen.
