= Crear un host manualmente en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para los hosts que no pueden ser descubiertos automáticamente, puedes crear un host manualmente. Crear un host es uno de los pasos necesarios para que la storage array sepa qué hosts están conectados a ella y para permitir el acceso de I/O a los volúmenes.

.Acerca de esta tarea
Ten en cuenta estas directrices cuando crees un anfitrión:

* Se deben definir los puertos identificadores de host que están asociados con el host.
* Asegúrese de proporcionar el mismo nombre que el que asignó el sistema al host.
* Esta operación no tiene éxito si el nombre que eliges ya está en uso.
* La longitud del nombre no puede superar 30 caracteres.


.Pasos
. Selecciona el menú:Almacenamiento[Hosts].
. Haz clic en menú:Crear[Host].
+
Aparece el cuadro de diálogo Crear host.

. Seleccione la configuración del host que corresponda.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Valor | Descripción 


 a| 
Nombre
 a| 
Escriba un nombre para el host nuevo.



 a| 
Tipo de sistema operativo de host
 a| 
Seleccione el sistema operativo que funciona en el host nuevo de la lista desplegable.



 a| 
Host interface type
 a| 
(Opcional) Si la cabina de almacenamiento es compatible con más de un tipo de interfaz del host, seleccione el tipo de interfaz del host que desea usar.



 a| 
Puertos de host
 a| 
Debe realizar una de las siguientes acciones:

** *Selecciona la interfaz E/S*
+
Por lo general, los puertos de host deben haber iniciado sesión y estar disponibles en la lista desplegable. Puede seleccionar los identificadores de puerto de host de la lista.

** *Añadir* manualmente
+
Si un identificador de puerto de host no aparece en la lista, significa que el puerto de host no ha iniciado sesión. Puedes usar una utilidad HBA o la utilidad del iniciador iSCSI para encontrar los identificadores de puerto de host y asociarlos con el host.

+
Puedes introducir manualmente los identificadores de los puertos host o copiarlos/pegarlos desde la utilidad (uno a la vez) en el campo *Puertos host*.

+
Debes seleccionar un identificador de puerto host a la vez para asociarlo con el host, pero puedes seguir seleccionando tantos identificadores como estén asociados con el host. Cada identificador se muestra en el campo *Host ports*. Si es necesario, también puedes eliminar un identificador seleccionando la *X* junto a él.





 a| 
Iniciador CHAP
 a| 
(Opcional) Si seleccionaste o introdujiste manualmente un puerto de host con un iSCSI IQN, y si quieres exigir que un host que intente acceder a la matriz de almacenamiento se autentique usando Challenge Handshake Authentication Protocol (CHAP), selecciona la casilla de comprobación *CHAP initiator*. Para cada puerto de host iSCSI que seleccionaste o introdujiste manualmente, haz lo siguiente:

** Introduzca el mismo secreto CHAP que se estableció en cada iniciador de host iSCSI para la autenticación de CHAP. Si va a utilizar la autenticación CHAP mutuo (autenticación bidireccional que permite la validación de un host en la cabina de almacenamiento y de una cabina de almacenamiento en el host), también debe configurar el secreto CHAP para la cabina de almacenamiento en la configuración inicial o cambiar la configuración.
** Deje el campo en blanco si no requiere la autenticación del host.


Actualmente, el único método de autenticación iSCSI que usa System Manager es CHAP.

|===
====
. Haz clic en *Crear*.


.Resultados
Una vez que el host se creó correctamente, el sistema crea un nombre predeterminado para cada puerto de host configurado para el host (etiqueta de usuario).

El alias por defecto es <``Hostname_Port Number``>. Por ejemplo, el alias por defecto para el primer puerto creado para  `host IPT is IPT_1`.
