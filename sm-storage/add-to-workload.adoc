= Añade volúmenes a una carga de trabajo en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes agregar uno o más volúmenes a una carga de trabajo existente o nueva para volúmenes que no están actualmente asociados a una carga de trabajo.

.Acerca de esta tarea
Los volúmenes no se asocian a una carga de trabajo si se los creó mediante la interfaz de línea de comandos (CLI) o si se migraron (importaron/exportaron) desde una cabina de almacenamiento diferente.

.Pasos
. Selecciona el menú:Storage[Volumes].
. Selecciona la pestaña *Aplicaciones y cargas de trabajo*.
+
Se muestra la vista Aplicaciones y cargas de trabajo.

. Selecciona *Añadir a la carga de trabajo*.
+
Aparece el cuadro de diálogo Select Workload.

. Realice una de las siguientes acciones:
+
** *Add volumes to an existing workload* -- Selecciona esta opción para añadir volúmenes a una carga de trabajo existente.
+
Use el menú desplegable para seleccionar una carga de trabajo. El tipo de aplicación asociada a la carga de trabajo se asigna a los volúmenes que se añaden a esta carga de trabajo.

** *Add volumes to a new workload* -- selecciona esta opción para definir una nueva carga de trabajo para un tipo de aplicación y añadir volúmenes a la nueva carga de trabajo.


. Selecciona *Siguiente* para continuar con la secuencia de añadir a la carga de trabajo.
+
Aparece el cuadro de diálogo Select Volumes.

. Seleccione los volúmenes que desea añadir a la carga de trabajo.
. Revise los volúmenes que desea añadir a la carga de trabajo seleccionada.
. Cuando estés satisfecho con la configuración de tu carga de trabajo, haz clic en *Finish*.
