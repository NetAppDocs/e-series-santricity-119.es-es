= Conoce los hosts y los clústeres de hosts en el software SANtricity
:allow-uri-read: 
:experimental: 
:icons: font

[role="lead"]
Puedes configurar hosts y clústeres de hosts, que definen las conexiones entre la matriz de almacenamiento y los servidores de datos.



== ¿Qué son los hosts y los clústeres de hosts?

Un _host_ es un servidor que envía I/O a un volumen en un storage array. Un _host cluster_ es un grupo de hosts, que puedes crear para asignar los mismos volúmenes a múltiples hosts.

Más información:

* link:host-terminology.html["Terminología de host"]
* link:access-volumes.html["Acceder a volúmenes"]
* link:maximum-number-of-luns.html["Número máximo de LUNs"]




== ¿Cómo configuro los hosts y los clústeres de hosts?

Para definir las conexiones de host, puedes ir al menú:Storage[Hosts] para configurar manualmente el host. Si quieres que dos o más hosts compartan el acceso al mismo conjunto de volúmenes, entonces puedes definir un cluster y asignar los volúmenes a ese cluster.
