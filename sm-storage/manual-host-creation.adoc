= Conoce la creación manual de host en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Crear un host es uno de los pasos necesarios para que la matriz de almacenamiento sepa qué hosts están conectados a ella y para permitir el acceso de I/O a los volúmenes. Solo puedes crear un host manualmente.



== Creación manual

La creación manual de hosts te permite asegurarte de que los identificadores de puerto de host que detectaron los controladores de la matriz de almacenamiento estén asociados correctamente con los hosts.

Durante la creación manual de hosts, debe seleccionar manualmente los identificadores de puerto de host o introducirlos manualmente para asociarlos. Después de crear un host, puede asignar volúmenes a él o añadirlo a un clúster de hosts si el objetivo es compartir el acceso a los volúmenes.
