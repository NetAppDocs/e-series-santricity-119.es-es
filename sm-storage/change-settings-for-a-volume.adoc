= Cambia la configuración de un volumen en SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes cambiar la configuración de un volumen, como su nombre, asignación de host, tamaño de segmento, prioridad de modificación, caché y así sucesivamente.

.Antes de empezar
El volumen que desea cambiar debe estar en estado óptimo.


NOTE: Es posible que algunas operaciones no estén disponibles mientras se realizan cambios en la configuración del volumen

.Pasos
. Selecciona el menú:Storage[Volumes].
. Selecciona el volumen que quieres cambiar y luego selecciona *Ver/Editar configuración*.
+
Aparece el cuadro de diálogo Configuración del volumen. Los ajustes de configuración del volumen que seleccionaste aparecen en este cuadro de diálogo.

. Selecciona la pestaña *Básico* para cambiar el nombre del volumen y la asignación de host.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Valor | Descripción 


 a| 
Nombre
 a| 
Muestra el nombre del volumen. Cambie el nombre de un volumen cuando el actual ya no sea significativo o no corresponda.



 a| 
Capacidades
 a| 
Muestra la Capacidad notificada y asignada del volumen seleccionado.

La capacidad informada y la capacidad asignada son las mismas para volúmenes gruesos, pero son diferentes para volúmenes delgados. Para un volumen grueso, el espacio físicamente asignado es igual al espacio que se informa al host. Para un volumen delgado, la capacidad informada es la capacidad que se informa a los hosts, mientras que la capacidad asignada es la cantidad de espacio de la unidad que está asignada actualmente para escribir datos.



 a| 
Pool / grupo de volúmenes
 a| 
Muestra el nombre y nivel de RAID del pool o grupo de volúmenes. Indica si el pool o grupo de volúmenes es compatible con la función de seguridad y si está habilitada.



 a| 
Host
 a| 
Muestra la asignación de volumen. Tú asignas un volumen a un host o cluster de hosts para que se pueda acceder a él para operaciones de I/O. Esta asignación concede a un host o cluster de hosts acceso a un volumen concreto o a varios volúmenes en una storage array.

** *Asignado a* -- Identifica el host o host cluster que tiene acceso al volumen seleccionado.
** *LUN* -- Un número de unidad lógica (LUN) es el número asignado al espacio de direcciones que un host utiliza para acceder a un volumen. El volumen se presenta al host como capacidad en forma de un LUN. Cada host tiene su propio espacio de direcciones de LUN. Por lo tanto, el mismo LUN puede ser usado por diferentes hosts para acceder a diferentes volúmenes.
+

NOTE: Para las interfaces NVMe, esta columna muestra el Namespace ID. Un namespace es almacenamiento NVM formateado para acceso en bloque. Es análogo a una unidad lógica en SCSI, que se relaciona con un volumen en la matriz de almacenamiento. El namespace ID es el identificador único del controlador NVMe para el namespace, y se puede establecer en un valor entre 1 y 255. Es análogo a un número de unidad lógica (LUN) en SCSI.





 a| 
Identificadores
 a| 
Muestra los identificadores del volumen seleccionado.

** *World-wide identifier (WWID)* -- un identificador hexadecimal único para el volumen.
** *Identificador único extendido (EUI)* -- un identificador EUI-64 para el volumen.
** *Identificador del subsistema (SSID)* -- El identificador del subsistema de almacenamiento de un volumen.


|===
====
. Selecciona la pestaña *Avanzado* para cambiar los ajustes de configuración adicionales de un volumen en un pool o en un grupo de volúmenes.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Valor | Descripción 


 a| 
Información de carga de trabajo y aplicación
 a| 
Durante la creación del volumen, es posible generar cargas de trabajo específicas de la aplicación u otras cargas de trabajo. Si corresponde, se muestran el nombre de la carga de trabajo, el tipo de aplicación y el tipo de volumen del volumen seleccionado.

Es posible cambiar el nombre de la carga de trabajo, si así lo desea.



 a| 
Configuración de calidad de servicio
 a| 
*Desactivar permanentemente el aseguramiento de datos* -- Esta opción solo aparece si el volumen tiene activado el aseguramiento de datos (DA). DA comprueba y corrige los errores que puedan ocurrir cuando los datos se transfieren a través de los controladores hasta las unidades. Usa esta opción para desactivar permanentemente DA en el volumen seleccionado. Cuando está desactivado, DA no se puede volver a activar en este volumen.

*Activar comprobación de redundancia de pre-lectura* -- Esta opción solo aparece si el volumen es un volumen grueso. Las comprobaciones de redundancia de pre-lectura determinan si los datos de un volumen son consistentes cada vez que se realiza una lectura. Un volumen que tiene esta función activada devuelve errores de lectura si el firmware del controlador determina que los datos son inconsistentes.



 a| 
Propiedad de la controladora
 a| 
Define la controladora designada como la controladora propietaria, o primaria, del volumen.

La propiedad de la controladora es sumamente importante y debe planificarse con cuidado. Las controladoras deben equilibrarse lo más posible en cuanto a las operaciones de I/O totales.



 a| 
Ajuste de tamaño del segmento
 a| 
Muestra el ajuste de tamaño de los segmentos, que solo aparece para los volúmenes de un grupo de volúmenes. Puedes cambiar el tamaño de los segmentos para optimizar el rendimiento.

*Transiciones de tamaño de segmento permitidas* -- System Manager determina las transiciones de tamaño de segmento que están permitidas. Los tamaños de segmento que son transiciones inapropiadas del tamaño de segmento actual no están disponibles en la lista desplegable. Las transiciones permitidas suelen ser el doble o la mitad del tamaño de segmento actual. Por ejemplo, si el tamaño de segmento de volumen actual es 32 KiB, se permite un nuevo tamaño de segmento de volumen de 16 KiB o 64 KiB.

*Volúmenes habilitados para caché SSD* -- Puedes especificar un tamaño de segmento de 4 KiB para volúmenes habilitados para caché SSD. Asegúrate de seleccionar el tamaño de segmento de 4 KiB solo para volúmenes habilitados para caché SSD que manejen operaciones de I/O de bloques pequeños (por ejemplo, tamaños de bloque de I/O de 16 KiB o menores). El rendimiento podría verse afectado si seleccionas 4 KiB como tamaño de segmento para volúmenes habilitados para caché SSD que manejen operaciones secuenciales de bloques grandes.

*Cantidad de tiempo para cambiar el tamaño del segmento* -- La cantidad de tiempo para cambiar el tamaño del segmento de un volumen depende de estas variables:

** La carga de I/O desde el host
** La prioridad de modificación del volumen
** La cantidad de unidades del grupo de volúmenes
** La cantidad de canales de unidades
** La capacidad de procesamiento de los controladores de la matriz de almacenamiento Cuando cambias el tamaño de segmento de un volumen, el rendimiento de I/O se ve afectado, pero tus datos siguen estando disponibles.




 a| 
Prioridad de modificación
 a| 
Muestra la configuración de la prioridad de modificación, que solo aparece para los volúmenes en un grupo de volúmenes.

La prioridad de modificación define cuánto tiempo de procesamiento se asigna a las operaciones de modificación de volumen en relación con el rendimiento del sistema. Puedes aumentar la prioridad de modificación de volumen, aunque esto podría afectar el rendimiento del sistema.

Mueva las barras del control deslizante para seleccionar un nivel de prioridad.

*Índices de prioridad de modificación* -- El índice de prioridad más bajo beneficia el rendimiento del sistema, pero la operación de modificación tarda más. El índice de prioridad más alto beneficia la operación de modificación, pero el rendimiento del sistema podría verse comprometido.



 a| 
Caching
 a| 
Muestra la configuración de la caché, que puedes cambiar para influir en el rendimiento general de I/O de un volumen.



 a| 
Caché SSD
 a| 
Muestra la configuración de caché SSD, que puedes activar en volúmenes compatibles como una forma de mejorar el rendimiento de solo lectura. Los volúmenes son compatibles si comparten las mismas capacidades de seguridad de la unidad y garantía de datos.

*La función de caché SSD utiliza uno o varios discos de estado sólido (SSD) para implementar una caché de lectura*. El rendimiento de las aplicaciones mejora gracias a los tiempos de lectura más rápidos de los SSD. Como la caché de lectura está en la matriz de almacenamiento, la caché se comparte entre todas las aplicaciones que usan la matriz de almacenamiento. Simplemente selecciona el volumen que quieres almacenar en caché y luego el almacenamiento en caché es automático y dinámico.

|===
====
. Haz clic en *Guardar*.
+
System Manager cambia la configuración del volumen en función de tus selecciones.



.Después de que termines
Selecciona menú:Home[View Operations in Progress] para ver el progreso de las operaciones de cambio que se están ejecutando actualmente para el volumen seleccionado.
