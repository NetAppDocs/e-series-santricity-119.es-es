= Conoce el número máximo de LUN en el software SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La matriz de almacenamiento tiene un número máximo de números de unidades lógicas (LUN) que puedes usar para cada host.

El número máximo depende del sistema operativo del host. La matriz de almacenamiento realiza un seguimiento del número de LUNs usados. Si intentas asignar un volumen a un host que supera el número máximo de LUNs, el host no puede acceder al volumen.
