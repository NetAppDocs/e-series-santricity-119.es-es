= Conoce los gráficos de rendimiento y las directrices en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La página Rendimiento te muestra gráficos y tablas de datos que te permiten evaluar el rendimiento de la matriz de almacenamiento en varias áreas clave.

Las funciones de rendimiento te permiten realizar estas tareas:

* Consulta los datos de rendimiento casi en tiempo real para ayudarte a determinar si una matriz de almacenamiento está teniendo problemas.
* Exporta datos de rendimiento para construir una vista histórica de una matriz de almacenamiento e identificar cuándo comenzó un problema o qué lo causó.
* Selecciona los objetos, las métricas de rendimiento y el periodo de tiempo que quieres ver.
* Compara métricas.


Puedes ver los datos de rendimiento en tres formatos:

* *Gráfico en tiempo real* -- Muestra los datos de rendimiento en un gráfico en tiempo real.
* *Tabular en tiempo casi real* -- Muestra datos de rendimiento en una tabla en tiempo casi real.
* *Archivo CSV exportado* -- Permite guardar datos tabulares de rendimiento en un archivo de valores separados por comas para verlos y analizarlos después.

[[guidelines-for-viewing-performance-data]]
== Pautas para ver los datos de rendimiento

* La recopilación de datos de rendimiento está siempre activada. No hay opción para desactivarla.
* Cada vez que transcurre el intervalo de muestreo, se consulta la storage array y se actualizan los datos.
* Para los datos gráficos, el marco temporal de 5 minutos admite actualizaciones cada 10 segundos, promediadas durante 5 minutos. Todos los demás marcos temporales se actualizan cada 5 minutos, promediados durante el marco temporal seleccionado.
* Los datos de rendimiento en las vistas gráficas se actualizan en tiempo real. Los datos de rendimiento en la vista de tabla se actualizan en tiempo casi real.
* Si un objeto supervisado cambia durante el tiempo en que se recopilan los datos, es posible que el objeto no tenga un conjunto completo de puntos de datos que abarquen el marco temporal seleccionado. Por ejemplo, los conjuntos de volúmenes pueden cambiar a medida que se crean, eliminan, asignan o desasignan volúmenes, o las unidades se pueden añadir, eliminar o averiar.
