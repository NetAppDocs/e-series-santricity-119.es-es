= Conoce la duplicación síncrona en el software SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La función de replicación síncrona proporciona replicación de datos en línea y en tiempo real entre matrices de almacenamiento a distancia.

[NOTE]
====
Esta función no está disponible en el sistema de almacenamiento EF600/EF600C o EF300/EF300C.

====


[[what-is-synchronous-mirroring]]
== ¿Qué es la replicación síncrona?

_Synchronous mirroring_ replica los volúmenes de datos en tiempo real para garantizar una disponibilidad continua. Los controladores de matrices de almacenamiento gestionan la operación de mirroring, que es transparente para las máquinas host y las aplicaciones de software.

Este tipo de mirroring es ideal para fines de continuidad de negocio, como la recuperación de desastres.

[[how-do-i-configure-synchronous-mirroring]]
== ¿Cómo configuro la replicación síncrona?

Debes usar la interfaz de Unified Manager para realizar la configuración inicial de reflejo entre las arrays. Una vez que esté configurado, puedes gestionar los pares reflejados en System Manager.
