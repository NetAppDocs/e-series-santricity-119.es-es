= Conoce la duplicación asíncrona en el software SANtricity
:allow-uri-read: 
:icons: font

[role="lead"]
La función de Mirroring asíncrono proporciona un mecanismo a nivel de controlador, basado en firmware, para la replicación de datos entre una matriz de almacenamiento local y una matriz de almacenamiento remota.



[[what-is-asynchronous-mirroring]]
== ¿Qué es el mirroring asíncrono?

_La replicación asíncrona_ captura el estado del volumen primario en un momento específico y copia solo los datos que han cambiado desde la última captura de imagen. El sitio primario puede actualizarse inmediatamente y el sitio secundario puede actualizarse a medida que lo permite el ancho de banda. La información se almacena en caché y se envía más tarde, a medida que los recursos de red están disponibles.

La replicación asíncrona se crea por volumen pero se gestiona a nivel de grupo, lo que te permite asociar un volumen reflejado remoto distinto con cualquier volumen primario en una matriz de almacenamiento determinada. Este tipo de replicación es ideal para satisfacer la demanda de operaciones ininterrumpidas y, en general, es mucho más eficiente en cuanto a recursos de red para procesos periódicos.

[[how-do-i-configure-asynchronous-mirroring]]
== ¿Cómo configuro el mirroring asíncrono?

Debes usar la interfaz de Unified Manager para realizar la configuración inicial de mirroring entre las arrays. Una vez que esté configurado, puedes gestionar los mirrored pairs y los consistency groups en System Manager.
