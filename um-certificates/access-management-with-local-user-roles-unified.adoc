= Gestión de acceso con roles de usuario locales en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Los administradores pueden usar las capacidades de RBAC (control de acceso basado en roles) aplicadas en SANtricity Unified Manager. Estas capacidades se conocen como "roles de usuario locales".



== Flujo de trabajo de configuración

Los roles de usuario locales están preconfigurados en el sistema. Para usar roles de usuario locales para la autenticación, los administradores pueden hacer lo siguiente:

. Un administrador inicia sesión en Unified Manager con un perfil de usuario que incluye permisos de Security admin.
+
[NOTE]
====
El `admin` usuario tiene acceso completo a todas las funciones del sistema.

====
. Un administrador revisa los perfiles de usuario, que están predefinidos y no pueden modificarse.
. Opcionalmente, el administrador asigna nuevas contraseñas para cada perfil de usuario.
. Los usuarios inician sesión en el sistema con sus credenciales asignadas.




== Gestión

Cuando usas solo roles de usuario locales para la autenticación, los administradores pueden realizar las siguientes tareas de gestión:

* Cambia las contraseñas.
* Establece una longitud mínima para las contraseñas.
* Permite que los usuarios inicien sesión sin contraseñas.
