= Cambia las contraseñas de los perfiles de usuario locales en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes cambiar las contraseñas de los usuarios en Gestión de acceso.

.Antes de empezar
* Debes iniciar sesión como administrador local, lo que incluye permisos de Root admin.
* Debes conocer la contraseña del administrador local.


.Acerca de esta tarea
Ten en cuenta estas directrices a la hora de elegir una contraseña:

* Cualquier nueva contraseña de usuario local debe cumplir o superar la configuración actual para una contraseña mínima (en View/Edit Settings).
* Las contraseñas distinguen mayúsculas de minúsculas.
* Los espacios finales no se eliminan de las contraseñas cuando se establecen. Ten cuidado de incluir espacios si se incluyeron en la contraseña.
* Para mayor seguridad, usa al menos 15 caracteres alfanuméricos y cambia la contraseña con frecuencia.


.Pasos
. Selecciona *Access Management*.
. Selecciona la pestaña *Local User Roles*.
. Selecciona un usuario de la tabla.
+
El botón Cambiar contraseña se vuelve disponible.

. Selecciona *Cambiar contraseña*.
+
Se abre el cuadro de diálogo Change Password.

. Si no se ha establecido una longitud mínima de contraseña para las contraseñas de los usuarios locales, puedes seleccionar la casilla para requerir que el usuario introduzca una contraseña para acceder al sistema.
. Ingresa la nueva contraseña para el usuario seleccionado en los dos campos.
. Ingresa tu contraseña de administrador local para confirmar esta operación y luego haz clic en *Cambiar*.


.Resultados
Si el usuario está conectado en ese momento, el cambio de contraseña hace que la sesión activa del usuario termine.
