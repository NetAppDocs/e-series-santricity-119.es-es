= Cambia la configuración de la contraseña del usuario local en SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes establecer la longitud mínima requerida para todas las contraseñas nuevas o actualizadas de usuarios locales. También puedes permitir que los usuarios locales accedan al sistema sin ingresar una contraseña.

.Antes de empezar
Debes iniciar sesión como administrador local, lo que incluye permisos de Root admin.

.Acerca de esta tarea
Ten en cuenta estas directrices a la hora de establecer la longitud mínima de las contraseñas de los usuarios locales:

* Los cambios de configuración no afectan las contraseñas de usuario locales existentes.
* La configuración de la longitud mínima requerida para las contraseñas de los usuarios locales debe estar entre 0 y 30 caracteres.
* Cualquier nueva contraseña de usuario local debe cumplir o superar la configuración actual de longitud mínima.
* No establezcas una longitud mínima para la contraseña si quieres que los usuarios locales accedan al sistema sin introducir una contraseña.


.Pasos
. Selecciona *Access Management*.
. Selecciona la pestaña *Local User Roles*.
. Selecciona *Ver/Editar configuración*.
+
Se abre el cuadro de diálogo Configuración de contraseña de usuario local.

. Debe realizar una de las siguientes acciones:
+
** Para permitir que los usuarios locales accedan al sistema _sin_ introducir una contraseña, desmarca la casilla "Requerir que todas las contraseñas de los usuarios locales sean como mínimo".
** Para establecer una longitud mínima de contraseña para todas las contraseñas de usuarios locales, selecciona la casilla de verificación "Requerir que todas las contraseñas de usuarios locales sean al menos" y luego usa el cuadro giratorio para establecer la longitud mínima requerida para todas las contraseñas de usuarios locales.
+
Cualquier nueva contraseña de usuario local debe cumplir o superar la configuración actual.



. Haz clic en *Guardar*.
